# Quantitative Multi-Asset Financial Intelligence & Backtesting Platform

## Overview

A quantitative finance platform for analyzing historical market data,
measuring financial risk, studying asset correlations, and backtesting
quantitative trading strategies.

## Assets

The platform supports:

- Gold
- Bitcoin
- NVIDIA

## Main Features

### Data Processing
- Historical market data collection
- Data cleaning
- Data normalization

### Quantitative Analysis
- SMA
- EMA
- Daily returns
- Cumulative returns
- Historical volatility
- Annualized volatility
- Sharpe ratio
- Maximum drawdown
- Rolling returns
- Correlation analysis
- Rolling correlation

### Backtesting
- SMA Crossover
- EMA Trend Strategy
- Momentum Strategy
- Mean Reversion Strategy
- Initial capital
- Position sizing
- Transaction costs
- Portfolio value
- Buy-and-Hold benchmark

### Dashboard
- Price trends
- SMA/EMA charts
- Returns
- Volatility
- Drawdowns
- Correlation heatmaps
- Buy/Sell signals
- Equity curves
- Strategy vs benchmark comparison
